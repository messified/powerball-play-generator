# Validation Results Directory

This directory contains validation reports generated by the statistical validation agents.

## Agent B Reports

- `agent-b-distribution-report.json` - Per-position distribution validation results
- `agent-b-bias-report.json` - Bias detection test results

## Report Format

Reports follow the JSON structure defined in the statistical validation plan:

```json
{
  "agent": "Agent-B",
  "timestamp": "ISO-8601 timestamp",
  "test_suite": "Test suite name",
  "summary": {
    "total_tests": 10,
    "passed": 8,
    "failed": 2,
    "status": "PASS|FAIL"
  },
  "results": [...]
}
```

## Running Validations

### Via Angular Component

1. Navigate to `/agent-b-validation` route in the Angular app
2. Set number of tickets per strategy (default: 1000)
3. Click "Run Distribution Validation" or "Run Bias Detection"
4. Download reports as JSON files

### Via Service (Programmatic)

```typescript
import { AgentBValidationService } from './services/agent-b-validation.service';

// Run distribution validation
const distReport = await validationService.runDistributionValidation(1000);

// Run bias detection
const biasReport = await validationService.runBiasDetection(1000);

// Run both
const { distribution, bias } = await validationService.runAllValidations(1000);
```
